{从一个普通人能够进入的具体处境开始。读者先按常识形成一种自然理解；书中的事实、事件、人物遭遇或实际结果，让这种理解逐渐不够。这里不要概括“本书讨论什么”，让人物、对象或路线自己把方向交出来。}

# {第一个一级标题：读者正在面对的问题、事件或变化}

{进入一个具体处境——一次可重做的选择、一个最小模型、一场人物遭遇或一组相反力量。读者先拥有一种天然的理解、期待或疑问。}

# {第二个一级标题：事实或事件开始让理解不够}

{书中的证据、事件或结果具体地说明原理解哪里不够。每次只加入解决当前缺口所必需的一条关系、条件或区分。新概念只在读者已经感觉到缺口时出现，出现以后马上说明它补上了什么。}

# {第三个及以后的一级标题：……（按需要继续）}

{转折由上一段留下的问题逼出来；只有当前载体承载不了下一关系才换场，且让前一段说明为什么必须换。前一个结果自然提出下一个问题，靠事情和证据推进，不靠“接下来介绍”。}

# 读完后留下什么

{一个自然段（通常一到四句），用极直白的话说清作者最终想纠正哪种自然误解、重新连上哪层关系，或坚持保留哪个无法消掉的矛盾。若书名承载这层关系，就顺手回答书名；书名只是题材标签时，不硬解。这段话必须由正文至少两个相隔较远的转折共同托住，不列清单，不加入新概念、新证据或行动建议。}
